# Support

This repository provides reusable rule files for AI coding agents and supporting
validation configuration.

## Getting Help

No dedicated support channel is currently documented for this repository.

For non-sensitive questions, use the repository's normal GitHub collaboration
channels when they are available, such as issues or pull requests. Include the
goal, relevant file, observed behavior, expected behavior, and validation
commands already run.

Do not include secrets, credentials, private URLs, tokens, exploit details, or
other sensitive data in public support requests.

## Before Asking

- Read `README.md` for repository purpose, file roles, installation, and
  validation commands.
- Read `CONTRIBUTING.md` before preparing a repository change.
- Check `TODO.md` for known follow-up work.
- Run the relevant validation commands from `README.md` when practical.

## Good Support Requests

- State whether the question concerns agent behavior, documentation rules,
  language rules, commit rules, release rules, CI, or validation tooling.
- Link or quote the smallest relevant rule section.
- Explain what outcome you expected and what outcome you observed.
- List the commands or checks already run, including any failures.

## Out of Scope

- Emergency operational support.
- Private consulting, custom policy design, or project-specific rule ownership
  unless maintainers explicitly agree.
- Sensitive vulnerability reports in public channels; use `SECURITY.md` for
  security reporting guidance.
